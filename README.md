---Avance del proyecto---

*En el simbolo del sistema instale el uv y cree los primeros archivos del proyecto. Depues hice el primer commit con esos archivos.

*El codigo del proyecto esta realizado en Visual Studio. en graph.py se escribira la estrucura del grafo y en el main las funciones para poder verlos.

*La forma de representar un grafo no dirigido sera con tres nodos A, B y C que se conectan A-B y B-C, entonces no hace ningun tipo de recorrido.

*La forma de representar un grado dirigido sera con tres nodos A, B y C que se conectan A->B->C, entonces se esta dirigiendo hacia un punto.

*El codigo en main.py permite organizar el grafo como pide en el pdf, ademas de tener un test_graph para probar su funcionamiento.

*Dentro del codigo main añado una funcion para determinar si un grafo es conexo o no.

*Se añadio en el main una funcion para ver si el grafo es ciclico.
